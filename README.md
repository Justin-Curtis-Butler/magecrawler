# magecrawler
A CLI text based python game for a mage crawling a dungeon. 

This is still a work in progress.

To play this game first copy the game to your system:
```git clone https://github.com/Justin-Curtis-Butler/magecrawler```

Then run 
```python main.py```

Or
```python3 main.py```

from the folder magecrawler
